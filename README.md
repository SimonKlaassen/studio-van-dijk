# Studio van Dijk

Portfoliosite van Merel van Dijk.

## Werken beheren
Ga naar `/admin` op de site (bijvoorbeeld https://simonklaassen.github.io/studio-van-dijk/admin/) en log in met GitHub.
Daar kun je werken toevoegen, wijzigen, verwijderen en de volgorde slepen. Na opslaan staat de wijziging binnen een paar minuten online.

## Waar staat wat
- `content/works.json`: alle werken (titel, categorie, foto, prijs, status)
- `content/site.json`: motto, e-mailadres en Instagram
- `img/uploads/`: foto's en video's die via /admin zijn geüpload
- `img/`, `vid/`, `spin/`: de oorspronkelijke beelden
